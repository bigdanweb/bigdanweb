## What I'm building

- **A production starter for small-business sites.** Architecture, privacy and security
  rules are enforced by lint and CI, not by memory. Every client site starts from it.
- **Booking and membership platforms** for local service businesses: schedules,
  payments, accounts, and an admin side for the owner.
- **Studio ops.** One private repository that watches every client site: uptime,
  usage against vendor limits, weekly audits, and alerts only when something changes.
- **Client sites and online stores**, built to load in under a second.

## How I work

- Obvious over clever. I read this code again in six months.
- Tests, accessibility and security from the first commit, not after launch.
- Rules live in tooling. If the docs say "never", something fails the build.
